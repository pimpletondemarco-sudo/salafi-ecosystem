# Halal Etsy Agents

AI agent team for a halal Etsy printables business (Salafi homeschool workbooks for children).

- `CLAUDE.md` — sourcing rules, design rules and workflow every agent follows
- `.claude/agents/` — manager, market-researcher, source-researcher, citation-checker, workbook-designer
- `research/` — market reports
- `products/` — one folder per product (sources, verification, output PDFs)
