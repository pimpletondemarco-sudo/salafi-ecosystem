# Design research reports

Owner rule (2026-10-17): no page or visual of any kind is designed until the market-researcher has
studied how well-selling competitors design that kind of page. One report per page type:
`<page-type>-<date>.md` (e.g. `tracing-2026-10-17.md`). The manager checks a report under 90 days
old exists before assigning any design. See CLAUDE.md, workflow step 2c.
